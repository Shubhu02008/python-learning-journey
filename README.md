## Scientific Calculator

This repository now includes a fully functional desktop calculator project.

### Run it

```bash
python calculator.py
```

The calculator has a polished Tkinter interface with standard arithmetic,
parentheses, percentages, calculation history, previous-answer recall, memory
controls, constants, powers, roots, factorials, logarithms, and trigonometric
functions in degree or radian mode. Its **Graph** tab plots expressions such as
`sin(x)`, `x^2 - 4`, and `2x + 1` across a configurable x-axis range.

The expression engine is deliberately restricted: it supports calculator math,
not arbitrary Python code.

Run the automated checks with:

```bash
python -m unittest -v
```
